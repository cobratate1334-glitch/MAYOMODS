# Acceptance boundaries

Implemented fixes are in the existing Unity game. Only Roblox uses a website.
The legacy military JNI interface is unchanged; Java generates data and offscreen
PNG state while Unity owns presentation and native Life mutations.

Two old tests invented native caller state and missed real bugs. New checks run
the actual GetNextScenario producer and both AcceptChoice call tails, including
the old 1110 negative controls. Parent tests run original closure allocation and
ListItem overwrite. Images are checked through actual typed consumers and final
serialized file references. These remain explicit API doubles, not ART/GPU tests.

School progress/trials are optional saved activities. They do not fabricate
membership in an official stock school team. Original fight controls and school
punishment remain authoritative. Winning a practice match does not create a
professional win. Sports drills do not import a proprietary sports engine or
roster. New jobs use original qualification, application, age and pay rules.

Historical recruitment is a simplified country/year cohort model. Neutral Spain
has no invented world-war draft. Volunteering, medical acceptance, actual native
military induction, training, assignment and missions are separate steps. Service
ends at the documented annual war boundary. Native deployment counts are never
faked to unlock authored missions. This candidate does not add a full real-time
battlefield engine, new weapons physics, or a full historical law simulator.

Heist payout requires a completed successful job. Re-entry cannot charge another
preparation fee or pay the same split twice. Original custody consequences remain.
Peer support resolves the current living inmate. Family visits retain the prior
native relationship effect; a complete availability simulation is not added here.
