# MayoMods 1111 — playable repair

[Download the signed 1111 APK](https://gofile.io/d/zD3yF873) · 446,953,392 bytes.

This extends the exact delivered 1110 APK. It fixes two reproduced native caller
contract errors and replaces the reported school/action dead ends with connected
original-game flows. Only Roblox uses a website.

The original fight engine receives the real Blueprint argument, returns the
original punch/kick/target Scenario, and uses the current classmate. Parent story
entries capture the actual native parent before the original menu overwrites its
local variable. This covers mother, father and step-parent without borrowing the
shared person preview.

Authored parent menus wait until original alert removal finishes. A queued native
Scenario takes priority. Managed list/controller roots use pointer-sized GC
handles; stale life owners are rejected. Tests reproduce both delivered-1110
failures using their original caller instructions.

School Life has six clear rows: exams, bullying, classmates, clubs, sports and the
year summary. Tests and trials resume their saved step. School effects use native
grades, popularity, health and relationships. The 48 supplied school illustrations
are imported under canonical resource IDs. News images resolve raw GFC tags at
the actual typed image API. Year cards retain the sourced real photographs. The
washed-out journal photo layer is removed; the earlier wartime palettes remain.

World War Service stays under Occupation and the existing Military menu. Its
country rules distinguish conscription, volunteering and neutrality. Active-war
training can finish in the same year. Existing soldiers can join a newly active
campaign. Native minigames still require real military service and current
training/assignment; stock deployment counts are not fabricated.

Heists keep one hub with saved stages and an earned-payout latch. Aborted or
failed jobs cannot leave free loot. Prison support uses the current inmate's
native response. Research jobs link a plan, field decision and paid report.
Eighteen additional jobs use the original full-time, part-time and freelance data
loaders and application/pay systems. Sports practices use short play decisions
and existing attributes, badges, tactics and training limits.

Build source: `native.py`, `content.py`, `build_dex.py`, `package.py`, `release.py`.
The baseline APK, metadata, private signer and diagnostics stay outside Git.
`references` documents exact boundaries, research and asset provenance. `reports`
contains sanitized results; reproducible commands are in `references/BUILD.md`.

The checks execute ARM64 branches and compiled Java classes with explicit managed
API/JNI/graphics doubles. They do **not** run Unity's renderer or Android ART.
Installation, real saves, touch/animation, the old black portrait/loading reports
and complete phone acceptance remain open. This is a repair candidate, not a
claim that every button in the entire game has been tested on a phone.
