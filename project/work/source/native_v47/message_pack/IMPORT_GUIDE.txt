JSON RECORD FIELDS
- id: unique stable message ID. All IDs are globally unique in this pack.
- platform: exact one of Reddit, Discord, YouTube, OnlyFans, SoundCloud.
- message_type: root post versus comment/reply type.
- surface: specific UI location for this type.
- destination: subreddit, Discord channel, YouTube video/live stream, creator membership area, or SoundCloud track.
- thread_id: the root message ID for this conversation.
- parent_id: null for roots; otherwise the ID of the direct parent message.
- username: fictional NPC username, or {{PLAYER_NAME}} for player-created roots.
- title: text for top-level posts; null on replies.
- text: natural-language NPC message; this is what the verified word count measures.
- topic: subject/topic filter for the current gameplay context.
- scenario: extra category label for feed filtering.
- trigger: world_feed (ambient), or a platform-specific player action.
- template_anchor: true means substitute real player-created post instead of inserting a generated fake player post.
- reply_to_player: whether a direct reply appears under a player-authored thread.
- sentiment: mood useful for NPC variety.
- like_count: sample numeric engagement; may be replaced by a game simulation.
- minutes_ago: example relative age for simulated feeds.
- age_gate: 18 for the age-gated platform; 0 elsewhere.
- timestamp_seconds: timed SoundCloud comments; null elsewhere.

GAME INTEGRATION NOTES
Build an in-game searchable index. A simple implementation may use files split by platform and select records by topic/scenario before displaying a feed. The text records are fictional content, not instructions to make external network calls. Persist used IDs in the current game save to reduce duplicates. A comment ID is not a thread ID; the root's id equals its thread_id. Root followed by children creates a valid discussion tree. Creator replies within age-gated OnlyFans threads can share the creator's username. Prevent adult-only platform access for under-18 characters. Avoid loading all records at the same time on mobile devices; read in chunks or convert the files to an indexed local database.
