# Original accessory artwork

Created with the built-in image generation tool, one call per accessory, with `transparent_background: true`. Project originals are `originals/cloche.png`, `originals/homburg.png`, `originals/pillbox.png` and `originals/snapback.png`. Fitted game textures are `assets/a44_accessory_24.png` through `assets/a44_accessory_27.png`.

Each prompt used this exact common text, substituting the subject below after “Primary request:”:

> Use case: stylized-concept. Asset type: single game portrait accessory sprite. Primary request: [SUBJECT]. One isolated hat, straight on front view, centered, suitable as a 2D overlay on a round cartoon avatar's head. Softly shaded illustrative fabric with gentle texture and clean alpha edges, comparable to detailed BitLife accessory art. Flat straight-on perspective, symmetrical head opening; no face, head, person, mannequin, labels, logos, watermark, cast shadow or scenery. Hat only, complete silhouette with padding on all sides. Actual transparent background. Square canvas.
