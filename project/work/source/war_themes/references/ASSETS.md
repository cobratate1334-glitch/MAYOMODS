# Restored existing art

These are the exact four 512x768 illustrated panels cropped without resampling
from native_immersion/inputs/war_background_atlas.png, originally packaged in 1109:
WWI trenches, WWI homecoming meadow, WWII city and WWII homecoming station.
The owner explicitly selected these existing illustrations in the latest request.
No new artwork is generated. Only native1109/background/{ww1,post1,ww2,post2}
textures/sprites are restored; news photos, school art, era picker images and all
other resources remain unchanged. The original 0.30 background alpha is retained.
