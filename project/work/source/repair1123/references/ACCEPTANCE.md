# Phone acceptance still required

Install as an update using the existing identity, keep app data, and check version
1123, launch, resume and save/reload. Do not uninstall or clear saves.

1. Choose 1800/1820/1900/1921/2024 and a typed 1837. Back must immediately show
   the selected year on the existing New Life panel. Starting the life must use
   that year. Cancelling the draft must keep the current running life unchanged.
2. Alternate year, country, regions, genetics and the native face editor. Genetics
   must have its own heading, native blue/green rows, readable icons and preserved
   scrolling. Preview, Save, cancel and Back must retain their intended choices.
3. Choose natural hair and each genetic pattern; age repeatedly within a stage
   and across 3/12/21/45/65, including old eras and modern years. Test both genders,
   current portraits, native header, save/reload and rewind. Check the old 0x21
   appearance crash does not recur; a different crash still requires its trace.
4. Check all nine older hair styles on baby/child/teen/adult/older male/female
   heads, including the reported spiked locs. Individual native head-shape choices
   and layers still require visual review; automated geometry is not phone proof.
5. Retain Golden Resume/regular/part-time era gates, modern freelance/special/
   social dates, school fight, wanted/bounty, creator and original World Cup.
6. Check original selected/dark/war themes and clear journal. Measure scrolling
   and age-up latency on the device; these automated cases do not measure FPS.

The wider gameplay/history report is not universally fixed by this release.
