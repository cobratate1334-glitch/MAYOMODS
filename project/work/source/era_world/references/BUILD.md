# Build 1119

Run from project/ with ../.venv/bin/python and
`PYTHONPATH=work/source:work/source/native_v29`. This is a frozen ARM64 patch
pipeline, not the original Unity editor project.

Private inputs:

- Signed 1118 APK, SHA256
  `3924a19e3f67fdf8b68bab7362445abd3759d8d5730e33b23934a1d66f87964e`.
- Its native library and complete manifest, SHA256
  `0b927d0d2d7dedcb475bea306ca7fadcf823300d1ae6fb4b852b2447f83aa0fa`.
- Retained native/API fixtures from era_refresh; copy them into WORK/fixtures,
  then replace native_hooks.json with this candidate's manifest and update only
  genesis_rework_defaults in fixtures/assets.json. Do not replace all old menu
  fixtures with later overlays, which would duplicate inherited builder rows.
- Actual 1118 TextAssets in WORK/base_assets.json. Tests currently use
  /workspace/build_work/era-world-1119. Overlay is generated by content.build.
- Existing development identity, Java and aapt2, outside Git.

The C compiler is Debian gcc-14-aarch64-linux-gnu 14.2.0-19cross1 with matching
binutils. codec_build.py uses MAYO_CROSS (default
/workspace/toolchains/cross1119/usr), temporary files and explicit freestanding
flags. No compiler packages or binaries belong in source. Selected PNGs and
their exact hashes are included. The raw owner packs remain private; optional
prepare_artwork.py can reconstruct the reachable selection from those packs.

1. `python -m era_world.native BASE_NATIVE BASE_MANIFEST WORK/libil2cpp.so WORK/native.json`
2. Repeat into a second native output and compare actual bytes. Only after that
   comparison write reproduction.json with the digest and result.
3. `python -m era_world.validate_structure BASE_NATIVE WORK/libil2cpp.so WORK/native.json WORK/structure_validation.json`
4. Generate WORK/overlay.json with content.build(base_assets). Refresh the
   fixture manifest/schema as described above before running tests.
5. `python -m era_world.run_tests WORK native_tests` (9)
6. `python -m era_world.run_tests WORK retained_tests` (15)
7. `python -m era_world.run_tests WORK content_tests` (8)
8. `python -m era_world.run_tests WORK menu_tests` (13)
9. `python -m era_world.package SIGNED_1118.apk WORK`
10. `python -m era_world.validate WORK`
11. `python -m era_world.release WORK PRIVATE_IDENTITY JAVA AAPT2`

Use the same WORK for binary, manifest, fixtures, overlays, tests and packaging.
run_tests records native/content hashes before and after each suite. validate
collects those completed logs and binds them to the staged bytes; it does not
rerun tests or perform phone checks. The gate expects 45 successful cases and
115 typed, reachable image resources. The final native is pinned in package.py:
`707e53c828d1b49dfaddb54b9c028327a3f45a078a4b2aa0d09fe560fb5684d4`.

Signing retains com.candywriter.bitlife and existing certificate SHA256
`bb8062953a3abe6ed051c29f4d39051d8266940c912323560baa3b795ddd92ef`.
VersionCode becomes 1119. Every DEX/JNI/launcher payload stays identical to 1118.
The gate verifies signature, native signer, aapt2 package parsing, payload
preservation and 16 KB uncompressed native alignment. APK-only upload remains
authorized; never publish raw upload replies, tokens, keys or raw evidence.
