HOW TO USE
Import files in sprites/ as 2D sprites with alpha enabled.
Every individual PNG has 6 pixels of transparent padding.
Maximum sprite dimension: 224 pixels.
Use manifest.json to find names, sizes, categories and source-sheet regions.
Sheets are 1536 x 1024 transparent WebP files. Object positions vary slightly,
so use the individual sprites or manifest bounds instead of blindly slicing
the sheet into equal grid cells.

Soldiers are complete single-pose illustrations, not skeletal rigs.
Effects are individual static images with alpha, not animation sequences.
Animate position/scale/opacity in the game as needed. Most props are intended
for icons or small scenes. The uniforms, vehicles and medals are stylized
era-inspired fictional artwork, not verified real historical models/awards.

Most PNGs use 128-color compression. The twelve effect images retain RGBA
to preserve their softer transparency. Larger versions are in the sheets.
generation_prompts.txt contains the original prompts for future variants.
No APK or game code is included.
