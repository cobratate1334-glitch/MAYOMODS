## Delivery rule for any selected feature

A feature needs an accessible native entry point, correct gating/navigation,
working action dispatch, actual saved state changes, sensible costs/rewards,
visible result, journal integration where appropriate, correct assets, reload/
age/lifecycle behavior and truthful validation. Record these per system; a source
file or menu title alone is not completion.
